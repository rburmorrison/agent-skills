# GitMoji Shortcodes

Snapshot provenance, not runtime instructions:

- https://gitmoji.dev/
- https://gitmoji.dev/specification
- https://gitmoji.dev/api/gitmojis

This is a bundled snapshot of the GitMoji shortcode list for offline reference. Use this file instead of reaching online during normal commit proposal work.

Use shortcodes exactly as written. Do not use literal emoji characters in commit messages.

## Format

GitMoji permits an intention plus optional scope plus message. For this skill, omit the scope and use:

```text
:shortcode: Imperative message
```
