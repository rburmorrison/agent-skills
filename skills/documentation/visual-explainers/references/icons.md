# Icon Catalog

Original 24×24 monoline SVGs, 1.75 stroke, round caps/joins. Use the names below in `icon` fields. For custom SVG/HTML, read the matching `assets/icons/NAME.svg` and inline it. The builder embeds icons automatically when referenced by supported components.

## Reading and Sources

- `document`: Read a prose document.
- `book`: Read an open book.
- `definition`: Find the explanation of a term.
- `quotation`: Identify quoted words.
- `source-link`: Follow a cited reference.
- `external-link`: Open an external destination.

## Information and Status

- `note`: Provide additional information.
- `tip`: Offer a useful suggestion.
- `important`: Emphasize essential information.
- `warning`: Warn of a possible problem.
- `caution`: Flag a risk with serious consequences.
- `success`: Confirm a successful outcome.
- `error`: Identify an error.
- `question`: Ask for clarification.

## Reader Controls

- `contents`: Show the table of contents.
- `chevron`: Indicate a direction.
- `search`: Search within the content.
- `expand`: Expand the view.
- `close`: Dismiss the view.
- `copy`: Copy the selection.
- `download`: Download a file.
- `print`: Print the content.
- `zoom-in`: Increase magnification.
- `zoom-out`: Decrease magnification.
- `theme`: Change the document appearance.
- `layout`: Arrange content within a layout.

## Interactive Examples

- `play`: Run the example.
- `pause`: Pause the example.
- `step-forward`: Advance one step.
- `reset`: Restore the initial state.
- `settings`: Adjust the controls.
- `edit`: Edit or draw.

## Relationships

- `connection`: Connect two endpoints.
- `branch`: Split one path into two.
- `merge`: Combine paths into one.
- `loop`: Repeat a cycle.
- `hierarchy`: Show a parent and its children.
- `group`: Collect items in a group.
- `intersection`: Identify the overlap of two sets.

## Processes and Time

- `input`: Move into a system.
- `output`: Move out of a system.
- `transformation`: Change one form into another.
- `steps`: Follow an ordered process.
- `clock`: Represent time or duration.
- `history`: Review earlier states.
- `target`: Identify the intended outcome.

## Data and Comparison

- `table`: Read data in rows and columns.
- `line-chart`: Trace a trend across values.
- `bar-chart`: Compare values by height.
- `scatter-plot`: Inspect a set of paired observations.
- `distribution`: Inspect the shape of a distribution.
- `comparison`: Compare two quantities.
- `filter`: Restrict results to a subset.
- `measurement`: Measure a length.

## Software and Systems

- `code`: Identify source code.
- `terminal`: Work at a command prompt.
- `file`: Represent a generic file.
- `folder`: Organize files in a folder.
- `package`: Represent a packaged component.
- `database`: Represent a data store.
- `server`: Represent a server.
- `network`: Represent linked machines.

## People and Context

- `person`: Identify an individual.
- `team`: Identify a group of people.
- `organization`: Identify an institution.
- `globe`: Represent worldwide context.
- `location`: Mark a place.
- `image`: Represent a picture.

## Spatial

- `cube`: Represent a solid in three dimensions.
- `layers`: Separate stacked surfaces.
- `plane`: Represent a flat surface.
- `depth`: Measure below a surface.
